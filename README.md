# 🛒 SISTEMA-VENTAS

Sistema de gestión de ventas desarrollado en **PHP y MySQL**, diseñado para administrar de manera eficiente las operaciones comerciales de un negocio. Permite registrar productos, gestionar clientes, controlar las ventas realizadas y llevar un seguimiento del inventario, facilitando la organización y control de las transacciones comerciales.

---

## 🛠 Funcionalidades principales

- ✅ Registro y administración de productos
- ✅ Gestión de clientes
- ✅ Registro de ventas
- ✅ Control de stock de productos
- ✅ Generación de comprobantes de venta
- ✅ Reportes de ventas y movimientos

---

## 💻 Tecnologías utilizadas

- PHP  
- MySQL  
- HTML  
- CSS  
- JavaScript
